# The Mom Test Simulator

Тренажёр навыков проблемных интервью (кастдева) по методологии
["Спроси маму"](https://momtestbook.com/) Роба Фицпатрика.

Пользователь ведёт диалог с AI-персоной (респондентом). Параллельно
второй AI-агент в реальном времени оценивает вопросы интервьюера и
начисляет штрафы/баллы за наводящие и гипотетические вопросы, питчинг
и поощряет открытые вопросы о прошлом опыте.

## Стек

- React + Vite
- Tailwind CSS v4
- lucide-react

## Статус

MVP в разработке. Сейчас реализован Frame 2 (рабочий экран: чат +
live-дашборд со Score Widget) на моках, без реальных вызовов LLM.
Следующие шаги — Frame 1 (онбординг), Frame 3 (итоги сессии) и
интеграция с Google Gemini через serverless-прокси.

## Разработка

```bash
npm install
npm run dev
```
