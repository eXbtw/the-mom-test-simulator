# The Mom Test Simulator

Тренажёр навыков проблемных интервью (кастдева) по методологии
["Спроси маму"](https://momtestbook.com/) Роба Фицпатрика.

Пользователь ведёт диалог с AI-персоной (респондентом). Параллельно
второй AI-агент в реальном времени оценивает вопросы интервьюера и
начисляет штрафы/баллы за наводящие и гипотетические вопросы, питчинг
и поощряет открытые вопросы о прошлом опыте.

## Стек

- React + Vite, Tailwind CSS v4, lucide-react
- Vercel Serverless Functions (`/api`) как прокси к Google Gemini —
  API-ключ живёт только на сервере и не попадает в клиентский код

## Статус

Все три экрана из PRD реализованы: онбординг (B2B/B2C → категория →
респондент) → рабочий экран (чат + live-дашборд) → итоги сессии с
разбором ошибок. Онбординг предлагает 6 готовых персон плюс
конструктор — можно описать свою нишу свободным текстом, и Gemini
сгенерирует респондента на лету (`/api/persona-builder`). Все три
AI-эндпоинта (`/api/persona`, `/api/evaluator`, `/api/persona-builder`)
используют один и тот же Gemini-провайдер — заводить отдельного
провайдера ради генерации персон не стали, это разовый вызов за
сессию, экономия токенов незначительна.

## Разработка

Только фронтенд (без вызовов AI — запросы к `/api/*` будут падать):

```bash
npm install
npm run dev
```

Полноценный локальный запуск с работающими AI-эндпоинтами:

1. Получите бесплатный ключ в [Google AI Studio](https://aistudio.google.com/apikey).
2. Скопируйте `.env.example` в `.env` и впишите `GEMINI_API_KEY`.
3. Запустите:

```bash
npm run dev:full
```

Это поднимет Vite (порт 5173) и локальный API-сервер (порт 8787,
`server/dev-api.js` — переиспользует те же хендлеры из `/api`), Vite
проксирует `/api/*` на него. Открывайте `http://localhost:5173`.

(Раньше здесь использовался `vercel dev`, но он не поднимает свой
прокси-слой поверх Vite 8 / Node 24 и просто зависает — поэтому для
локальной разработки используется `server/dev-api.js`. На деплое на
сам Vercel это не влияет, там `/api` работает как обычно.)

## Деплой

Проект деплоится на [Vercel](https://vercel.com) как есть — Vite-фронтенд
и `/api` определяются автоматически. Не забудьте добавить `GEMINI_API_KEY`
в Environment Variables проекта на Vercel.
