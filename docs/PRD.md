# Product Requirements Document (PRD): The Mom Test AI Simulator

## 1. Контекст и суть продукта
**Продукт:** Веб-приложение (React + Tailwind) для тренировки навыков кастдева (проблемных интервью) по методологии "Спроси маму" (Rob Fitzpatrick).
**Целевая аудитория:** Продакт-менеджеры, UX-исследователи, фаундеры.
**Платформа:** Одностраничное веб-приложение (SPA), работающее в браузере (через Claude Artifacts).
**Главная механика:** Пользователь ведет диалог с AI-персоной. Под капотом работают два независимых AI-агента: один отыгрывает респондента, второй в реальном времени анализирует вопросы пользователя и начисляет штрафы/баллы.

## 2. Архитектура AI-агентов (Prompt Logic)

### Агент 1: Респондент (Persona)
* **Роль:** Владелец корпоративного автопарка (B2B). 
* **Легенда:** Управляет 50 автомобилями. Главная головная боль — простои машин из-за ДТП, проблемы со страховыми выплатами и текучка водителей. 
* **Правила поведения:**
  * Никогда не выходить из роли.
  * Если пользователь задает гипотетический вопрос ("А вы бы купили страховку за Х рублей?"), отвечать социально одобряемо ("Да, звучит отлично, купил бы").
  * Раскрывать реальные боли (прошлый опыт) только если пользователь задает открытые вопросы о прошлом ("Расскажите, как вы решали проблему с последним ДТП?").
  * Ответы должны быть короткими (1-3 предложения), как в живом разговоре.

### Агент 2: Аудитор (Mom Test Evaluator)
* **Роль:** Оценщик диалога.
* **Функция:** Анализирует каждую реплику пользователя (интервьюера) и возвращает JSON с оценкой.
* **Критерии ошибок (Triggers):**
  * `leading_question`: Наводящий вопрос (Штраф -10 баллов).
  * `hypothetical`: Вопрос о будущем/гипотезах (Штраф -10 баллов).
  * `pitching`: Продажа своей идеи вместо исследования (Штраф -20 баллов).
  * `good_question`: Открытый вопрос о прошлом опыте (Плюс +15 баллов).

## 3. Структура экранов (Иерархия для переноса в Figma)

**Frame 1: Onboarding & Setup**
* `Header`: Название симулятора + короткое описание.
* `Card Container` (Выбор персоны):
  * `Persona Card`: Имя, Роль (Владелец автопарка), Уровень сложности (Hard).
  * `Button`: "Начать интервью".

**Frame 2: Workspace (Split-screen)**
* `Left Panel` (Чат):
  * `Chat History`: Область прокрутки сообщений.
  * `Message Bubble (User)`: Серого цвета, выравнивание вправо.
  * `Message Bubble (AI)`: Синего цвета, выравнивание влево.
  * `Input Field`: Текстовое поле + Кнопка "Отправить".
* `Right Panel` (Live Dashboard):
  * `Score Widget`: Круговой прогресс-бар (от 0 до 100%).
  * `Tags/Chips`: Индикаторы выявленных инсайтов (серые по умолчанию, зеленые при раскрытии).
  * `Alert Box`: Всплывающие подсказки от Агента-Аудитора (появляются при совершении ошибки).

**Frame 3: Session Results**
* `Summary Title`: Итоговый счет и грейд (Например: "Junior Researcher").
* `Mistakes List`: Аккордеон с разбором: "Ваш вопрос -> Почему это ошибка -> Как надо было спросить".
* `Button`: "Попробовать снова".

## 4. Требования к разработке (для Claude)
1. Используй React, стейт-менеджмент через `useState` и `useEffect`.
2. Стилизация: Tailwind CSS + иконки Lucide React.
3. Логика должна быть полностью изолирована на клиенте (Mock-запросы к LLM для начала, затем я прикручу API-ключ).
4. Весь код должен быть выведен в одном Artifact для удобного просмотра и тестирования.

## 5. Первый шаг разработки
Напиши базовую структуру React-приложения, реализуй Frame 2 (Split-screen) с замоканным чатом и Score Widget. Пока без реальной интеграции с AI, только верстка и базовая логика обновления стейта при отправке сообщения.
